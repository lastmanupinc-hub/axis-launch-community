# AXIS Launch — community

Discussions for founders, auditors, and acquirers working out what it actually takes to launch,
verify, and sell an AI-generated app. The seeded, moderated archive lives on the site —
[https://jonathanarvay.com/community](https://jonathanarvay.com/community) — and this repo's Discussions are where new threads start.

Six categories, each with a job and a structured format (the form appears when you open a new
discussion in that category):

| Category | For |
|---|---|
| Find a Co-founder | partner search — intro format required, both directions |
| Auditors & Security | audit requests and auditor introductions; sellers disclose |
| Investors & Fundraising | raise prep and term questions — **no securities offerings**, discussion only |
| Show & Tell | build logs and launches in progress; feeds the listing pipeline |
| M&A & Exit Readiness | diligence, valuation, Trust Fabric Passport — admin-answered |
| Platform Q&A | help with AXIS Launch itself |

Ground rules are the site's [community guidelines](https://jonathanarvay.com/legal/community-guidelines). Short
version: real identities for anyone selling a service, numbers with dates, no hype that
wouldn't survive one rewrite request. Moderation follows the guidelines ladder; threads are
locked rather than deleted.
